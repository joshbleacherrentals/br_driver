# Inspection Photo Upload Setup

## Overview

The inspection photo upload system allows drivers to attach photos to pre-trip and post-trip inspections. Photos are stored in Supabase Storage and metadata is tracked in the `InspectionPhotos` table.

## Database Setup

### 1. Create the InspectionPhotos Table

```sql
create table public."InspectionPhotos" (
  photo_id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  inspection_id bigint not null
    references public."WorkTrackerInspections"(inspection_id)
    on delete cascade,
  storage_path text not null,  -- e.g. 'inspections/123/456.jpg'
  caption text
);
```

### 2. Create Storage Bucket

In Supabase Dashboard:

1. Go to Storage
2. Create a new bucket named `inspection-photos`
3. Set it to **Public** (so drivers can view uploaded photos)
4. Set up RLS policies if needed:

```sql
-- Allow authenticated users to upload
create policy "Authenticated users can upload photos"
on storage.objects for insert
to authenticated
with check (bucket_id = 'inspection-photos');

-- Allow authenticated users to view photos
create policy "Authenticated users can view photos"
on storage.objects for select
to authenticated
using (bucket_id = 'inspection-photos');

-- Allow users to delete their own photos
create policy "Users can delete photos"
on storage.objects for delete
to authenticated
using (bucket_id = 'inspection-photos');
```

### 3. Add RLS Policies to InspectionPhotos Table

```sql
-- Allow authenticated users to insert photos
create policy "Authenticated users can insert photos"
on public."InspectionPhotos"
for insert
to authenticated
with check (true);

-- Allow authenticated users to view photos
create policy "Authenticated users can view photos"
on public."InspectionPhotos"
for select
to authenticated
using (true);

-- Allow authenticated users to delete photos
create policy "Authenticated users can delete photos"
on public."InspectionPhotos"
for delete
to authenticated
using (true);
```

## Installation

### Install Required Packages

```bash
npx expo install expo-image-picker
```

### Update app.json

Add camera and photo library permissions:

```json
{
  "expo": {
    "plugins": [
      [
        "expo-image-picker",
        {
          "photosPermission": "The app accesses your photos to let you upload inspection images.",
          "cameraPermission": "The app accesses your camera to let you take inspection photos."
        }
      ]
    ],
    "ios": {
      "infoPlist": {
        "NSCameraUsageDescription": "This app uses the camera to capture inspection photos.",
        "NSPhotoLibraryUsageDescription": "This app accesses your photo library to upload inspection images."
      }
    },
    "android": {
      "permissions": [
        "android.permission.CAMERA",
        "android.permission.READ_EXTERNAL_STORAGE",
        "android.permission.WRITE_EXTERNAL_STORAGE"
      ]
    }
  }
}
```

## Usage

### In InspectionForm Component

The photo uploader is automatically integrated into the inspection form:

```tsx
<InspectionPhotoUploader inspectionId={inspectionId} />
```

### Features

- **Camera capture**: Take photos directly with device camera
- **Gallery selection**: Choose existing photos from device
- **Real-time upload**: Photos upload to Supabase Storage immediately
- **Delete photos**: Remove uploaded photos with confirmation
- **Pending queue**: Photos taken before inspection is submitted are queued and uploaded automatically
- **Loading states**: Visual feedback during upload/delete operations

### Workflow

1. Driver starts inspection form
2. Fills out checklist items
3. Adds notes
4. Can take/upload photos (initially disabled until inspection is submitted)
5. After submitting inspection, the inspection ID is created
6. Photo upload button becomes enabled
7. Photos are uploaded to `inspections/{inspection_id}/{timestamp}.jpg`
8. Database records are created in `InspectionPhotos` table

## Files Created

### Components

- `components/InspectionPhotoUploader.tsx` - Photo upload UI component

### Database Layer

- `db/inspectionPhotos.ts` - CRUD operations for photos
  - `uploadInspectionPhoto()` - Upload file and create DB record
  - `getInspectionPhotos()` - Fetch all photos for an inspection
  - `getPhotoPublicUrl()` - Get public URL for display
  - `deleteInspectionPhoto()` - Remove from storage and DB
  - `updatePhotoCaption()` - Update photo caption

### Types

- `types/inspectionPhoto.ts` - TypeScript interfaces

## Troubleshooting

### Photos not uploading

- Check Supabase Storage bucket exists and is named `inspection-photos`
- Verify bucket is set to Public
- Check RLS policies allow authenticated users to upload

### Permission errors

- Rebuild the app after adding expo-image-picker plugin
- Check app.json has correct permissions
- On iOS: Check Info.plist has usage descriptions
- On Android: Check AndroidManifest.xml has permissions

### Photos not displaying

- Verify bucket is Public
- Check `getPhotoPublicUrl()` is returning valid URLs
- Verify RLS policies allow SELECT on storage.objects
