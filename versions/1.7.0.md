### 🆕 What's New — see everything we ship

Open the **menu** (top right) **→ What's New.** Every update to the app now gets
written up here, newest first, so you can see what changed instead of noticing a
button moved.

A blue dot sits on the menu button and on the **What's New** row whenever there
is an update you haven't read yet. Opening the page clears it.

The whole page works with **no signal** — the notes ship inside the app itself,
so you can read them from a yard, a loading dock, or the middle of nowhere.
